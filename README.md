# HR ANALYTICS DASHBOARD | TABLEAU PROJECT

## Project Overview

This project is an interactive **HR Analytics Dashboard** developed in **Tableau** to analyze workforce trends, employee attrition, job satisfaction, department performance, overtime impact, and employee demographics.

The dashboard provides actionable HR insights that help organizations:

- Reduce employee attrition
- Improve employee satisfaction
- Identify high-risk departments
- Understand workforce demographics
- Analyze overtime impact on resignations
- Support data-driven HR decision-making

---

# Business Objective

The primary goal of this project is to answer critical HR business questions such as:

- Why are employees leaving the company?
- Which departments face the highest attrition?
- Does overtime increase employee turnover?
- Which age groups are more likely to resign?
- How does job satisfaction affect attrition?
- Which job roles experience maximum employee loss?
- How does salary influence employee satisfaction?
